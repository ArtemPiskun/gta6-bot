# GTA 6: мониторинг «что стреляет» и автопостинг в Telegram

Релиз GTA 6 назначен на **19 ноября 2026** и выходит по регионам, первой открывается Новая Зеландия. Пик трафика будет 18–21 ноября, поэтому в конфиге по умолчанию включён `launch_mode`.

## Что делает бот

Каждые 5–10 минут он проходит один цикл:

1. **Собирает сигналы**
   - YouTube-каналы из списка читаются через бесплатный RSS. Ключ не нужен, а в RSS уже есть число просмотров.
   - YouTube Data API (с ключом) ищет новые видео по «GTA 6 / ГТА 6 / GTA VI» за последние 24 часа и каждый цикл обновляет просмотры.
   - Новости берутся из Google News (EN и RU), PC Gamer, GameSpot, Eurogamer, StopGame, Reddit r/GTA6 и r/GamingLeaksAndRumours. Rockstar Newswire и YouTube-канал Rockstar помечаются как официальные источники.
2. **Считает score от 0 до 100**, то есть насколько материал «стреляет»:
   - для видео: просмотры в час (по разнице между замерами, а не за всё время), отрыв от обычного уровня канала (outlier), свежесть, официальный ли канал;
   - для новостей: вес источника, ключевые слова (трейлер, перенос, патч, оценки, PC, онлайн), подтверждение другими изданиями за 12 часов и затухание со временем.
   - Если про новость пишут два издания, она получает ✅. Сливы без подтверждения публикуются только при очень высоком score и с пометкой «Слух».
3. **Сам находит новых блогеров.** Канал, у которого видео набирает больше 5000 просмотров в час, автоматически добавляется в отслеживаемые.
4. **Публикует в Telegram** самое сильное из того, что не публиковалось. За цикл выходит не больше одного поста, выдерживаются лимиты в час и минимальный интервал. Одна и та же история повторно не публикуется, даже если её перескажет другое издание. Английские новости можно автоматически пересказывать по-русски через Claude (нужен `ANTHROPIC_API_KEY`), без ключа пост выходит с оригинальным заголовком.
   - **Режим одобрения.** Если в `config.toml` указать `mode = "review"`, каждый пост сначала приходит вам в личку от бота с кнопками «Опубликовать» и «Пропустить». В режиме `auto` (по умолчанию) так проверяются только неподтверждённые слухи. Для обоих вариантов нужен `TELEGRAM_ADMIN_CHAT`.
5. **Каждый день в 20:00 МСК публикует сводку**: топ-10 видео за сутки и главные новости.
6. **Готовит данные для сайта**: файлы `news.json`, `trending.json` и `channels.json` (рейтинг блогеров) в `/mnt/project-files/gta6-site/content/`. Формат согласован с тредом сайта.

Пример поста:

```
🔥 GTA 6: вышел релизный трейлер
📺 Rockstar Games · 👁 5.1M · ⚡ 300K/час
▶️ Смотреть
#GTA6 #ГТА6 #Видео
```

## Что нужно от вас

| Что | Где взять | Обязательно? |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | @BotFather → /newbot | да |
| `TELEGRAM_CHANNEL` | @username канала. Бота нужно добавить в канал администратором с правом публикации | да |
| `YOUTUBE_API_KEY` | console.cloud.google.com → включить YouTube Data API v3 → Credentials → API key | очень желательно: без него видны только каналы из списка |
| `TELEGRAM_ADMIN_CHAT` | ваш chat_id (можно узнать у @userinfobot), сюда приходят ошибки | желательно |
| `ANTHROPIC_API_KEY` | console.anthropic.com | по желанию: русские пересказы английских новостей |

Квота YouTube API составляет 10 000 единиц в сутки. Один поиск стоит 100 единиц, поэтому бот делает один поиск раз в 20 минут (около 7200 единиц) и тратит примерно 1 единицу на обновление статистики 50 видео.

## Запуск

Внешних зависимостей нет, нужен только Python 3.11+.

**Вариант А, сервер или ПК (лучше всего на время релиза, цикл каждые 5 минут):**
```bash
cp .env.example .env    # вписать ключи
python -m gta6bot test-telegram   # проверка: бот пришлёт тестовое сообщение
DRY_RUN=1 python -m gta6bot run  # прогон без отправки, посты печатаются в консоль
python -m gta6bot loop           # боевой режим
```
На VPS: `gta6bot.service` (systemd).

**Вариант Б, GitHub Actions (без сервера, цикл каждые 10 минут, GitHub иногда запускает с опозданием):** запушить папку в репозиторий и добавить секреты в Settings → Secrets → Actions. Рабочие процессы уже лежат в `.github/workflows/`.

Полезные команды: `python -m gta6bot top` показывает топ сигналов, `python -m gta6bot digest` отправляет сводку сейчас.

## Настройка

Всё настраивается в `config.toml`: каналы, ленты, ключевые слова, пороги score, лимиты постов, тихие часы. После релиза, примерно с 22 ноября, поставьте `launch_mode = false`. Тогда пороги станут выше, постов будет меньше, а ночью с 2:00 до 8:00 МСК бот будет молчать.

## Разбор трёх видео из запроса

Все три видео не про саму игру, а про то, как заработать на волне GTA 6:

| Видео | Просмотры | Вывод для нас |
|---|---|---|
| Нольфин, «Как я сделаю миллионы на GTA6» (RU) | 105K, в 4 раза выше обычного для канала | 6 форматов без лица: новости, гайды, топы, шортсы, сравнения, реакции. Главное — скорость и англоязычная аудитория |
| AI Edge, «$10k+/mo with GTA 6 + AI» | 134K, 2.2K/час | Нарезка клипов, новостной канал на ИИ, гайды, сайт и Telegram, монетизация трафика. Всё автоматизировано через Claude |
| AI Vision, «GTA 6 Shorts Channel Using Claude» | 68K, в 38 раз выше обычного для канала | Шортсы на ИИ-сценариях. Выигрывает тот, кто первым подхватил тему |

Вывод: прямо сейчас, за 1–2 дня до релиза, выигрывает **скорость реакции**. Поэтому бот ставит в приоритет просмотры в час за последний замер и подтверждённые новости, а не объём.

По данным vidIQ на 17 ноября, сейчас быстрее всего растут видео стримеров (IShowSpeed, Kai Cenat, по 80–100 тысяч просмотров в час), форматы «Everything you need to know» и «что будет в ночь релиза» (TGG, TmarTn2, Vice City Dispatch), кроссоверы (NBA 2K27 × GTA 6) и видео «готовлю комнату или скачиваю GTA 6». ## Проверка

`python -m unittest discover tests` прогоняет весь цикл офлайн на тестовых данных: фильтр нерелевантного, официальный трейлер публикуется первым, подтверждение новостей, отсев дублей, порог для слухов, скорость по замерам, экспорт для сайта и сводка.
